Projects

PCB Assembly Fault Detection System

Capstone

An automated inspection system that finds assembly faults on populated PCBs, replacing a manual visual check that varies between operators. It runs on the AMD Kria KV260, a Zynq UltraScale+ MPSoC with Arm Cortex-A53 cores and FPGA fabric.

Board image→Pre-processing→INT8 YOLO on KV260→Faults boxed on output
  • Trained a YOLO deep-learning detector in Python on a labelled PCB defect dataset.
  • Quantized the FP32 model to INT8 to cut model size and inference latency.
  • Deployed the INT8 model onto the board for real-time inference, marking each fault with a bounding box so it traces to a component and location.
PlatformAMD Kria KV260
ModelYOLO, FP32 to INT8
StackPython, FPGA fabric

Bare-Metal Peripheral Drivers on ARM Cortex-M3

Ongoing

Register-level Embedded C for the NXP LPC1768 in Keil uVision. Pin-function, clock, timer and interrupt registers are configured straight from the datasheet.
